# Contributing

Thank you for improving the learning system. Contributions should make the template clearer, more accessible, and more effective at teaching transferable software engineering skills.

- Keep shared templates **language-neutral** unless the file is explicitly an example.
- Prefer small, focused changes with a clear explanation.
- Do not commit personal learning logs, private repository URLs, API tokens, passwords or personal data.
- Preserve the distinction between **planned curriculum** and **demonstrated progress**.
- Don't create fictional quotations or unsupported claims of verified tool behavior.
- Include sources for technical claims where appropriate, and test all relative Markdown links.
- Open a pull request describing the problem, proposed change, and how you verified it.

The project uses the MIT license. Contributions should be compatible with it.
