# Courses

**This directory starts empty on purpose.** Create courses according to your goals and demonstrated gaps rather than inheriting a mandatory syllabus.

Possible tracks include Programming Foundations, Data Structures & Algorithms, Frontend Engineering, Backend Engineering, Database Engineering, Software Testing, Security Engineering, Distributed Systems, Mobile Development, DevOps, and Systems Programming.

A course can use Python, Java, JavaScript, TypeScript, C#, Go, Rust, C++, Kotlin, PHP, or another language as appropriate. **No language or framework is required by this template.**

Copy the course templates from [Templates](../Templates/), then put actual evaluated lessons into `Lessons/`. Keep course roadmaps independent but reuse concepts across tracks instead of duplicating them.

For example:

```text
Courses/
  Web Engineering/
    Roadmap.md
    Learning Progress.md
    Review Queue.md
    Lessons/
    Reference/
```
