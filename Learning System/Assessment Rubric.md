# Assessment rubric

Assess **individual skills**, not a person's overall talent.

| Level | Meaning | Evidence |
| --- | --- | --- |
| Not assessed | No usable evidence yet | No demonstrated attempt |
| Recognized | Identifies a concept or follows a supplied explanation | Correct interpretation, perhaps after teaching |
| Guided | Solves with hints or targeted corrections | Record the help needed |
| Independent | Solves, explains and tests without hints in a defined task | Original solution, behavior check and reasoning |
| Retained / transferable | Recalls after a delay or applies correctly in a novel setting | Dated spaced recall or a different practical use |

Never assign broad mastery from a narrow task. Track conceptual explanation, code implementation, debugging and testing separately where it improves accuracy.

## Evidence types

- **Discussion:** explanation or code shown in a chat; does not by itself prove runtime behavior.
- **Source review:** an identified commit, file or diff was inspected.
- **Learner-reported execution:** command and results supplied by the learner, without independent execution.
- **Reviewer-executed verification:** explicitly run checks with observable results.

Mark completion only when the lesson objective is evaluated; missing breadth or delayed recall belongs in the review queue.
