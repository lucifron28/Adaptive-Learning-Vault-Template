# Start here — Software Engineering Learning Vault

This is a reusable, language-independent learning system. Its purpose is to turn assisted learning into independently demonstrated software engineering skill.

## First use

1. Read [the mentor prompt](Reusable%20Software%20Engineering%20Mentor.md) and paste it into an AI chat.
2. Choose an area of software engineering and describe a concrete goal. The mentor should ask about your experience and run a short adaptive diagnostic.
3. Use [Course Handoff](../Templates/Course%20Handoff.md), [Roadmap](../Templates/Roadmap.md), and [Learning Progress](../Templates/Learning%20Progress.md) to create your own course under `Courses/<Your Course>/`.
4. Choose a small learner-owned practice project after assessing prerequisites. Keep project code in a separate repository if useful.
5. Work through one interactive lesson at a time. Only record completion after an evaluated attempt.
6. Update the progress tracker, review queue, and handoff when a milestone is evaluated.

## When continuing

Give the mentor your existing `Learning Progress.md`, current handoff and (when relevant) the linked project repository. Ask it to resume the **exact next unfinished task** without repeating proven lessons.

## Source of truth

- `Learning Progress.md`: what you actually demonstrated and the next exercise.
- `Roadmap.md`: planned future learning, subject to change.
- `Lessons/`: evaluated lesson notes—not transcripts of every conversation.
- `Review Queue.md`: spaced-recall prompts.
- `Project Log.md`: source repository, reviewed commit and verification evidence.

GitHub/Obsidian integration is optional. Never assume the assistant has file or Git access; request explicit permission before changing repositories.
